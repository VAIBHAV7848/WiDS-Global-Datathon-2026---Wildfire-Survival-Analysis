## 🎯 The Problem

> **Predict** the probability that an active wildfire intersects high-value grid infrastructure (transmission lines, substations, roads) at **12h, 24h, 48h, and 72h** time horizons.

This is a **right-censored survival analysis** problem. Standard ML models fail here because they treat right-censored data as negative hits, incurring massive Brier score penalties. We bypassed this using our 3-Zone pipeline.

## 🧠 The Solution Strategy

We identified that strict `0.0` or `1.0` probability assertions crush your leaderboard rank through Brier score penalties. We implemented:
1. **3-Zone Geospatial Segregation:** ML only analyzes the uncertain "STATIC" zone. Hard geometry dictates the "ACTIVE" and "FAR" zones.
2. **Laplace Extrema Smoothing:** We replaced dangerous 0.001 assumptions with mathematical safety pillows (`0.015`) to prevent 1.0 penalization.
3. **Monotonicity Law:** Enforcing strictly ascending values across Time Horizons via $P(12h) \le P(24h)$.
